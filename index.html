Our next steps

Our ML roadmap on AWS

These phases describe future work. We have not moved this pipeline to Amazon Web Services (AWS).

Planned on AWS

Phase 1: foundation

Amazon S3 will store all media. Claude on Amazon Bedrock will help write scripts and check facts.

Bedrock embeddings will turn clips and stats into searchable representations, so creators can find related material.

Planned on AWS

Phase 2: GPU pipeline

Amazon EC2 G6e and G6 instances, with NVIDIA L40S and L4 GPUs, will run mask, swap, lip-sync, voice and caption jobs.

AWS Batch will queue jobs. AWS Step Functions will chain the steps. We plan to use Spot capacity to reduce costs.

Planned on AWS

Phase 3: our own models

Amazon SageMaker training jobs will train small LoRA adapters, which adapt existing models, and a model that ranks clips.

The ranking model will learn from nflverse play-by-play data, including expected points added (EPA) and win probability, to find strong clips.

Why AWS

AWS would put storage, GPUs and models in one place, with Claude on Bedrock next to the media in S3. Managed job queues would help a one-person team avoid running servers. Credits would let us move the GPU work that runs on Runpod today.

Creator in control

Responsible AI

These rules guide the working app and every planned feature.

  • A human approves every post. ShareFuze never publishes on its own.
  • Every parody voice carries a clear label.
  • Every stat comes from nflverse data, and the fact checker compares claims with it.
  • We do not train models on a creator's footage without that creator's consent.
